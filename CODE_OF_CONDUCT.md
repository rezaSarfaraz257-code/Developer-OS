# Code of Conduct

We value a respectful, inclusive, and productive environment.

## Expected behavior

- be respectful and professional
- welcome collaboration and feedback
- keep discussions constructive
- be considerate of different experience levels

## Unacceptable behavior

- harassment or discrimination
- abusive or threatening conduct
- insulting comments or personal attacks
- disruptive behavior in discussions or pull requests

## Enforcement

Project maintainers may remove or reject contributions that violate this code of conduct.
