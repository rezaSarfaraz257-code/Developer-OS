# Architecture

## Overview

Developer OS is organized into two main parts:
- Backend: Django + DRF + JWT
- Frontend: React + Vite

## Backend

Responsibilities:
- expose API endpoints
- authenticate users
- manage project CRUD
- serve user profile data

## Frontend

Responsibilities:
- render dashboard UI
- manage authentication state
- handle project operations
- search and visualize project data
- allow profile edit flow

## Core idea

The project acts like a developer-centric operating system for tasks, tools, notes, workflows, and project context.
