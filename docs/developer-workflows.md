# Developer Workflows

## Typical developer session

1. Log in to the dashboard.
2. Review project activity and metrics.
3. Search for relevant work items.
4. Open or create a project.
5. Update project details as needed.
6. Check profile information and preferences.

## Recommended practices

- keep project titles clear and specific
- use search to quickly find items
- document workflows and tools in project descriptions
- maintain a profile with contact and identity details
- keep project data consistent and actionable
